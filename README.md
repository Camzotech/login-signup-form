# Responsive Animated Login & Registration Form

A modern, responsive **Login & Registration Form** featuring smooth animated transitions between authentication views. Built from scratch using **HTML5, CSS3, and Vanilla JavaScript**, with a focus on clean UI, responsiveness, and simple implementation.

## ✨ Features

* 🎨 **Modern UI** — Clean and polished authentication interface.
* 🔄 **Animated Transitions** — Smooth sliding animations between Login and Registration forms.
* 📱 **Fully Responsive** — Designed to work across desktop, tablet, and mobile screen sizes.
* 🔐 **Authentication UI** — Login and registration form layouts ready to be connected to a backend authentication system.
* 🌐 **Social Login UI** — Includes visual buttons for Google, Facebook, GitHub, and LinkedIn.
* ⚡ **Zero Dependencies** — Built with pure HTML, CSS, and Vanilla JavaScript.
* 🎯 **Simple & Lightweight** — No frameworks or build tools required.

## 🛠️ Tech Stack

| Technology            | Usage                                                           |
| --------------------- | --------------------------------------------------------------- |
| **HTML5**             | Page structure and form elements                                |
| **CSS3**              | Styling, animations, gradients, Flexbox, and responsive layouts |
| **JavaScript (ES6+)** | Form switching and DOM interactions                             |
| **Google Fonts**      | Poppins typography                                              |
| **Boxicons**          | Interface icons                                                 |

## 🚀 Getting Started

No installation or build process is required.

### 1. Clone the repository

```bash
git clone https://github.com/MarluVT/login-signup-form.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd login-signup-form
```

### 3. Launch the website

Open:

```text
SignUp_LogIn_Form.html
```

in your preferred web browser.

That's it — the project runs entirely on the client side.

## 📱 Responsive Design

The interface is designed to adapt to different screen sizes:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

CSS media queries are used to modify the layout and form presentation on smaller screens.
